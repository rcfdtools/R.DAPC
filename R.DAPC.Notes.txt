Commands
	UNITS: configuración de unidades y parámetros
	LAYER: acceso a capas
	PTYPE: define the point type representation in the draw.
	MIRRTEXT: use zero for not mirror text.
	LTSCALE: change the drawing scale for lines.
	REGEN: regenerates the entire draw.
	REDRAW: refreshes the display in the current viewport.
	TXT2MTXT: convert separate text into multiline text.
	LAYER: abre el panel de capas.
	Ctrl+9: reopen de Command Line. COMMANDLINE or COMMANDLINEHIDE.
	Ctrl+1: show properties for the selected object.
	CUI: personalize user interface
	; al final de una sentencia en CUI corresponde a Enter en el teclado.
	^C al final de una sentencia en CUI corresponde a ESC en el teclado.
	Shift + Mouse Wheeler click = 3D orbit
	APPLOAD or AP: load an external app or lisp code.
	DELOBJ: variable de sistema para definir si al crear un elemento 3D a partir de un objeto, este se elimina o se mantiene. 3: elimina el objeto inicial luego de la extrusión. 0: se mantiene el objeto original. -1: AutoCAD solicita si se elimina o no el objeto original.
	MASSPROP: calcula el volumen de un sólido.
	JPGOUT: command or the PLOT command with a JPG plotter configuration. The JPGOUT command directly exports selected objects or the entire drawing and viewports to a JPEG file. 
	THICKEN or SURFSCULPT: convert surfaces to solids using .
	MV: crear una ventana en el espacio de papel.
